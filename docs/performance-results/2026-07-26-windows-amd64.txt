Preparation: migrate, seed, validate every physical connection's PRAGMAs, fully open and idle the pool, warm the row/cache, complete HTTP readiness, and reset the update value outside timing
Validation: every response, selected/affected row, row count, and final value checked; all samples passed
GORM: v1.31.2; PrepareStmt is configured globally, but SessionContext uses a dedicated sql.Conn, so these results are not labeled prepared-statement throughput
